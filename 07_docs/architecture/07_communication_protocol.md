# Communication Protocol

## Overview

The communication protocol defines how high-level decisions generated by the Raspberry Pi are transmitted to the ESP32 for real-time execution.

This layer connects:

- Voice + decision system (input + intelligence)
- Motor execution system (ESP32 + drivers)

---

## Position in System Architecture

The communication layer sits between **decision-making** and **execution**.

```text
Voice Input
    ↓
Command Parsing
    ↓
Decision Layer
    ↓
COMMUNICATION PROTOCOL
    ↓
ESP32 Execution
    ↓
Motor Control
